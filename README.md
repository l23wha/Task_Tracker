# Task Tracker CLI 📝

A simple Command Line Interface (CLI) application built with **Node.js** to track and manage your daily tasks. This project helps you manage tasks directly from your terminal with features to add, update, delete, and filter tasks by status.

---

## 🚀 Features

- **Add Tasks**: Quick task creation with auto-incrementing IDs.
- **Update Tasks**: Modify existing task descriptions.
- **Delete Tasks**: Remove tasks by ID.
- **Mark Status**: Set task status to `in-progress` or `completed`.
- **List & Filter**: View all tasks, or filter specifically by `done`, `in-progress`, or `not-done`.
- **JSON Persistence**: Automatically stores and reads tasks from a local `tasks.json` file.

---

## 🛠️ Requirements

- **Node.js** (v18 or higher recommended)
